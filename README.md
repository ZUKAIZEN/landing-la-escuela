# Landing La Escuela

Fuente de las plantillas y recursos visuales de este componente. El backend de Admin LIFETRAINER conserva las cuentas, los permisos, los productos, los pagos y las migraciones.

Este repositorio no se ejecuta como servicio independiente: Admin incorpora una revisión exacta y valida `frontend-manifest.json` antes de construir la aplicación. No contiene secretos, datos de clientes, modelos ni procesos de envío. Las plantillas usan los contextos y las rutas Django existentes; no son HTML estático.
